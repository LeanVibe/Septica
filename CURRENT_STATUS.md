# Current Status

Date: 2026-06-21

## Status

Septica is in validation, not public source release.

The live validation surface is:

https://septica.codeswiftr.com/

The current goal is to prove repeat play with a constrained player cohort before
adding monetization claims, broader feature promises, or App Store language.

## Public boundary

This repository intentionally does not contain the active implementation today.
It is a public status shell so that the project URL does not imply a shipped or
open-source product before that decision is made.

Current public claims that are safe:

- Septica is a card-game project in validation.
- A browser validation surface exists.
- The active iOS implementation is private while release/source decisions are
  pending.

Claims that are not safe yet:

- App Store availability.
- Paid/premium availability.
- Public multiplayer production readiness.
- Open-source source availability from this repository.

## Implementation boundary

The active native iOS work is currently tracked outside this public repository.
Before any source publication, the project needs an explicit decision on:

- source visibility;
- license;
- naming boundary between Septica and Sedma;
- App Store/TestFlight readiness;
- which claims are backed by current validation evidence.

## Validation boundary

The product remains in repeat-player validation. Public messaging should stay
focused on the validation surface and player cohort until there is evidence of:

- completed games;
- active players;
- return sessions;
- stable release path.
