# Septica

Septica is a card-game project currently in validation.

This public repository is a status and coordination surface, not the current
source distribution. The active iOS implementation is still private while the
gameplay slice, naming, and release path are being validated.

## Current status

- Public validation surface: https://septica.codeswiftr.com/
- Current phase: repeat-player validation
- Monetization: frozen until repeat-player evidence exists
- App Store: no public App Store listing yet
- Source: not published in this repository yet

See [CURRENT_STATUS.md](CURRENT_STATUS.md) for the current boundary.

## Why this repo exists

This repository keeps the public project URL truthful while the implementation
boundary is decided. It should not be treated as proof of a shipped App Store
app, production multiplayer service, or open-source release.

## Next decision

The next decision is whether Septica should remain a public status shell with a
private implementation, or whether the active iOS codebase should be prepared
for a public source release.
