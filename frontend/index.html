📋 Testing Scenario Steps:

  1. Open Two Browser Tabs/Windows:
    • Tab 1: http://localhost:3000 (Player 1)
    • Tab 2: http://localhost:3001 (Player 2)
  2. Connect Both Players:
    • Click "Connect" in both tabs
    • Verify both show "Connected" status
  3. Create Game (Tab 1):
    • Click "🚀 Create Game" button
    • Copy the generated Game ID
  4. Join Game (Tab 2):
    • Paste Game ID in the "Join Existing Game" field
    • Click "🚪 Join Game" button
  5. Play Complete Game:
    • Take turns playing cards (follow Romanian Septica rules)
    • Verify turn indicators work correctly
    • Check card validation (green = valid, red = invalid)
    • Monitor scores and game state synchronization
